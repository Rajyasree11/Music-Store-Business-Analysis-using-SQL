# SQL Project – Music Store Business Analysis

## 📌 Overview

Analyzed a **Music Store relational database using PostgreSQL** to answer business questions related to customers, sales, tracks, artists, genres, and countries.

## 🛠️ Tools & Skills

* PostgreSQL & pgAdmin 4
* SQL
* JOINs
* GROUP BY & ORDER BY
* COUNT, SUM & AVG
* Data Analysis

## 📊 Analysis Areas

* Customer & revenue analysis
* Sales by country
* Top-performing tracks
* Artist & album analysis
* Genre-based analysis
* Customer purchase behavior

## 🎯 Objective

To use SQL to transform raw data into **meaningful business insights** and strengthen practical Business Analyst skills.
